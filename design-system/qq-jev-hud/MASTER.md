# QQ Jev HUD Design System

> 本文件是项目 UI 的全局设计依据。具体页面存在 `pages/<page-name>.md` 时，以页面文件覆盖本文件中的对应规则。

## 产品形态

- 平台：Windows 10/11
- 技术栈：.NET 8 + WPF
- 类型：透明桌面覆盖层、聊天消息注释工具
- 视觉目标：像参考图一样在对应消息附近显示浅灰色 Jev 判断卡
- 密度：高
- 动效：低
- 交互原则：不抢焦点、不遮挡输入、不妨碍 QQ 原操作

## 布局原则

卡片位置按以下优先级决定：

1. 对方消息气泡下方
2. 对方消息气泡侧边的空白区域
3. 聊天区域右侧的固定注释轨道
4. 空间仍不足时折叠成小型 Jev 标记

覆盖层不能通过 Hook 或注入让 QQ 原生消息重新排版。卡片如果可能遮挡消息，应自动切换布局，而不是强行叠放。

## 颜色

| 语义 | 颜色 | 用途 |
| --- | --- | --- |
| 卡片背景 | `#F4F5F7` / 94% | 默认判断卡 |
| 主文字 | `#1F2329` | 标题与主要结论 |
| 次要文字 | `#646A73` | 百分比说明、时间与状态 |
| 边框 | `#D9DCE1` | 卡片轮廓 |
| 品牌强调 | `#3B82F6` | Jev 标识、焦点环 |
| 低风险 | `#2E8B57` | 风险 1～3 |
| 中风险 | `#B7791F` | 风险 4～7 |
| 高风险 | `#C93C37` | 风险 8～10 |
| 失败/过期 | `#8B9098` | 失败或失效结果 |

所有正文与背景对比度至少达到 4.5:1。风险状态必须同时显示颜色、文字和数字。

## 字体

- 字体族：`Segoe UI`, `Microsoft YaHei UI`, sans-serif
- 卡片标题：13 DIP，Semibold
- 正文：12～13 DIP，Regular
- 百分比：12 DIP，使用等宽数字特性时不得破坏中文排版
- 行高：1.4～1.5
- 禁止使用小于 12 DIP 的正文

## 间距

| Token | 值 | 用途 |
| --- | --- | --- |
| `Space2` | 2 DIP | 紧凑标签内部 |
| `Space4` | 4 DIP | 同组文本间距 |
| `Space8` | 8 DIP | 消息与卡片间距 |
| `Space12` | 12 DIP | 卡片内边距 |
| `Space16` | 16 DIP | 卡片组间距 |

## Jev 注释卡

- 默认宽度：280 DIP
- 允许范围：260～320 DIP
- 最大高度：220 DIP
- 圆角：8 DIP
- 边框：1 DIP
- 阴影：`0 2 8 rgba(0,0,0,0.10)` 的等效 WPF 阴影
- 默认不接受点击，不进入 Tab 顺序
- 鼠标移入后才显示“展开、隐藏、暂停”等次级操作
- 卡片正文最多显示 4 个候选项，更多内容折叠

### 内容顺序

1. `Jev` + 判断主题
2. 当前问题
3. 候选结论及概率
4. 可选的风险等级或建议动作
5. 低置信、过期或失败状态

## 状态

- 分析中：单行提示与小型脉冲点
- 已完成：显示当前消息最相关的判断
- 低置信：明确显示“上下文不足”，隐藏强建议
- 已过期：降低不透明度并尽快移除
- 失败：显示失败状态，不复用旧结果冒充当前结果

## 动效

- 进入：150～220 ms 淡入，Y 位移不超过 8 DIP
- 更新：变化字段交叉淡化
- 退出：120～180 ms 淡出
- 滚动跟随：位置直接同步，不使用滞后或弹簧
- 系统开启减少动画时，只保留必要的透明度变化

## WPF 实现规则

- 使用 Per-Monitor DPI Awareness V2
- 覆盖窗口设置为透明、置顶、不激活
- 交互控件设置 `AutomationProperties.Name`
- 所有必要操作都提供键盘路径和全局暂停快捷键
- 不依赖鼠标悬停才能访问关键状态
- 使用 Visual Studio 性能分析工具验证滚动跟随和卡片更新
- 避免在高频循环中重建完整可视树
- QQ 最小化、联系人切换或锚点丢失时立即隐藏相关卡片

## 禁止项

- 不使用夸张大标题、营销页布局或装饰性动效
- 不使用玻璃拟态导致文字低对比
- 不用 emoji 代替状态图标
- 不使用会改变布局的 Hover 缩放
- 不遮挡 QQ 输入框、工具栏、未读标记和消息正文
- 不显示看似精确但没有意义的小数概率
- 不把低置信判断写成确定事实

## 交付检查

- [ ] 每张卡片都能追溯到一个可见消息锚点
- [ ] 卡片碰撞时能切换到侧边轨道或折叠
- [ ] QQ 滚动时没有明显漂移或闪烁
- [ ] QQ 失焦或最小化时卡片按设置隐藏
- [ ] 主文字对比度达到 4.5:1
- [ ] 风险状态不只依赖颜色
- [ ] 暂停、隐藏、展开支持键盘操作
- [ ] 减少动画模式有效
- [ ] 卡片不抢占 QQ 输入焦点
- [ ] 不保存真实聊天截图或正文
