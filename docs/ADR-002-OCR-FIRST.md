# ADR-002：当前 QQ 版本采用 OCR-first 消息识别

- 状态：已接受
- 日期：2026-09-22

QQ 9.9.19 的公开辅助功能树只暴露 Chromium 渲染容器，不能可靠读取聊天正文。因此首版直接捕获 QQ 的可见窗口区域，并在项目专用的本地 PaddleOCR 进程中识别消息文字与坐标。

- 输入截图与识别结果仅停留在内存，标准输入输出使用 JSON Lines，不写入缓存或数据库。
- 每 350ms 检查一次画面；内容变化稳定约 950ms 后才进行一次 OCR。
- OCR 结果按垂直行组装消息，通过聊天区域的水平中心区分左侧来信与右侧发言。
- UI Automation 保留为未来版本的可选锚点信息来源，但不作为本版读取正文的前提。
- 截图无法获取、OCR 启动失败或 QQ 不在前台时，程序清空卡片并显示非阻塞状态。
