# QQ Jev HUD 快速上手

> 这里是 5 分钟速览。**完整使用手册见 [USAGE.zh-CN.md](USAGE.zh-CN.md)**（安装、Key 配置、看懂卡片、候选回复与话术、联系人背景卡、排查表、常见问题）。

1. 双击项目根目录的 `start.cmd`（或桌面快捷方式）。第一次会调用 `setup.ps1`，安装 .NET 8 SDK、项目专用 Python 环境和本地 PaddleOCR。
2. 打开 QQ，并进入想观察的聊天窗口（**QQ 要保持在前台**，卡片才会显示）。
3. 在系统托盘找到 QQ Jev HUD，选择“自动分析已开启”。程序先把当前可见消息当作基线，不会为旧消息补卡。
4. 收到新的左侧消息后，稳定约一秒会出现 Jev 判断卡（卡片顶部引用了“是谁说了什么”），同时弹出候选回复面板。
5. 要回复时，在候选面板里挑一条点「复制」或「填入 QQ」——**发送由你点**。
6. 如果卡片位置不准确，从托盘选择“重新校准聊天区域”，拖选 QQ 的消息历史区域，再重新开始分析。

从托盘「设置…」可选择判断引擎（Jev / OpenAI 兼容 LLM / Mock）、填写 Base URL / 模型 / API Key、调整卡片显示和隐私（发送前脱敏）。API Key 只存入 Windows 凭据管理器，不写进任何文件。

快捷键：`Ctrl + Alt + J` 暂停或恢复。退出或暂停会立即清空内存中的截图、消息和卡片。

## 不用 QQ 也能先看效果

```powershell
$exe = ".\src\QQJevHud\bin\Debug\net8.0-windows10.0.19041.0\QQJevHud.exe"
& $exe --preview-card      # 渲染一张示例判断卡
& $exe --preview-replies   # 显示候选回复面板
& $exe --open-settings     # 打开设置窗口
```

## 失败排查

- 显示“未找到 QQ”：确认 QQ 已打开且聊天主窗口没有最小化。
- 显示“OCR 暂不可用”：在项目根目录右键以 PowerShell 运行 `setup.ps1`，等待 OCR 依赖完成安装。
- 看不到卡片：QQ 需要位于前台；首版只分析点击“分析当前聊天”之后出现的新左侧消息。
