# QQ Jev HUD 使用说明

1. 双击项目根目录的 `start.cmd`。第一次会调用 `setup.ps1`，安装 .NET 8 SDK、项目专用 Python 环境和本地 PaddleOCR。
2. 打开 QQ，并进入想观察的聊天窗口。
3. 在系统托盘找到 QQ Jev HUD，选择“分析当前聊天”。程序先把当前可见消息当作基线，不会为旧消息补卡。
4. 收到新的左侧消息后，稳定约一秒会出现灰色 Jev 判断卡。首版卡片是本地模拟判断，不会上传任何聊天内容。
5. 如果卡片位置不准确，从托盘选择“重新校准”，拖选 QQ 的消息历史区域，再重新开始分析。

快捷键：`Ctrl + Alt + J` 暂停或恢复。退出或暂停会立即清空内存中的截图、消息和卡片。

## 失败排查

- 显示“未找到 QQ”：确认 QQ 已打开且聊天主窗口没有最小化。
- 显示“OCR 暂不可用”：在项目根目录右键以 PowerShell 运行 `setup.ps1`，等待 OCR 依赖完成安装。
- 看不到卡片：QQ 需要位于前台；首版只分析点击“分析当前聊天”之后出现的新左侧消息。
