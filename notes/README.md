# 联系人背景卡

在这个目录里放**以联系人命名**的 Markdown 文件，程序会把它作为该联系人的背景资料，随判断一起发给判断引擎。**保存即生效**，不需要重启。

## 用法

1. 在 QQ 里看着对方的名字，在 `notes/` 建一个同名文件，例如 `notes/茶.md`、`notes/妈妈.md`。
2. 用几句话写下你们的约定、雷区和近况：

```markdown
# 茶

- 约定：周末下午是我们的时间，别安排别的事。
- 雷区：别提加班和体重。
- 近况：她这周在准备考试，压力比较大。
- 称呼：平时叫她「茶茶」。
```

3. 下次她发来消息时，判断和候选回复就会带上这些背景。

## 说明

- 文件名要和 QQ 里显示的**聊天标题**一致（群名也可以）。
- 内容只在你自己的机器上；只有在你启用分析、收到新消息时，才会随当次请求发给你配置的判断服务商。
- 这个目录**不会**被提交到 Git（已在 `.gitignore` 里）。
- 单个文件建议不超过 1200 字，太长会被截断。
